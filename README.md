# Nike Store React - Evaluación Sumativa 3

Aplicación SPA desarrollada con React + Vite para la asignatura Programación Front End.

## 🚀 Requisitos
- Node.js 18+
- npm o yarn

## 📦 Instalación
```bash
# Clonar repositorio
git clone <repo-url>
cd nike-store-react

# Instalar dependencias
npm install

# Configurar variables de entorno
cp .env.example .env
# Editar .env con tus configuraciones

# Iniciar servidor de desarrollo
npm run dev
